# Keyboard usage — Twake Calendar

Every feature of Twake Calendar is meant to be usable with the keyboard alone. This page lists the
keys that are specific to the application; everything else follows the usual conventions of the
web (Tab / Shift+Tab to move between controls, Enter or Space to activate a button, Escape to
close a dialog or a menu).

The main shortcuts are also listed in the application: *Settings › Accessibility › Keyboard*.

Known gaps are tracked in the [action plan](A10Y_REMEDIATIONS-2026-10-01.md); please report any
other one with an issue labelled `accessibility`.

## Calendar

| Where | Keys | Effect |
|---|---|---|
| Event in the month, week or day view | Tab, then Enter or Space | Opens the event preview |
| Event in the Schedule view | Tab, then Enter or Space | Opens the event preview |
| "+N more" link in a day | Enter, then Escape | Opens / closes the list of the day's events |
| Mini calendar | Arrow keys, Page Up / Page Down, Home / End, Enter | Moves between days / months, goes to the chosen day |
| Navigation bar | Tab to *Today*, *Previous*, *Next* and the view selector | Changes the displayed period or view |
| *Create* button (sidebar or floating button) | Enter or Space | Creates an event — the keyboard alternative to selecting a slot with the mouse |

Moving or resizing an event by drag and drop has a keyboard alternative: open the event, *Edit*,
and change its dates and times in the form.

## Calendar list (sidebar)

| Where | Keys | Effect |
|---|---|---|
| Calendar checkbox | Space | Shows / hides the calendar |
| Calendar row | Shift+F10 or the Menu key | Opens the calendar actions (modify, delete, print, hide…), including in narrow layouts and at high zoom where the "more" button is not displayed |
| Booking link row | Enter or Space | Edits the booking link |
| Calendar colour (calendar settings) | Tab to the selected colour, then the arrow keys | Chooses another colour; Tab again reaches the custom colour button |

## Event form

| Where | Keys | Effect |
|---|---|---|
| Date or time field | Enter, Space or Alt+Arrow Down | Opens the date / time picker |
| Date picker | Arrow keys, Page Up / Page Down, Enter, Escape | Chooses a day, changes month, confirms, cancels |
| Editable time field | Type the time, Enter | Confirms the time; Escape restores the previous value |
| Guests field | Type a name or an address, Arrow keys and Enter | Picks a suggestion; Enter (or Space when typing an address) adds it |
| Guest chips | Arrow Left / Arrow Right from the empty guests field, then Backspace or Delete | Selects a guest, removes it |
| Any dialog | Escape | Closes the dialog (asks for confirmation when there are unsaved changes) |

## Search

| Where | Keys | Effect |
|---|---|---|
| Search field | Type, then Enter | Runs the search |
| Search result | Tab, then Enter or Space | Opens the event preview |

## Public booking pages

| Where | Keys | Effect |
|---|---|---|
| Date grid | Arrow keys, Enter | Moves between days, picks a day |
| Time slot | Tab, Enter or Space | Picks a time slot |
